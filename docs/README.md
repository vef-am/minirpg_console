# Documentation - MiniRPG Console

This folder contains the design and architectural documentation for the MiniRPG Console project.

## Files

### PROJECT_PLAN.md
Comprehensive project specification including:
- Project vision and goals
- Functional scope (MVP features)
- Character attributes and systems
- Combat rules and mechanics (v0.4 FINAL)
- AI behavior rules
- UX policies
- Risk assessment
- Design decision log

**Purpose**: Single source of truth for game design decisions

### IMPLEMENTATION_PLAN.md
Technical architecture and implementation guide:
- Class responsibilities and methods by module
- Data structures for each major component
- Dependency order for implementation
- Edge cases and validation rules
- File structure recommendations
- Integration points between modules

**Purpose**: Technical blueprint for code implementation

## Using These Documents

1. **During Development**: Keep PROJECT_PLAN.md and IMPLEMENTATION_PLAN.md open as reference
2. **Adding Features**: Update PROJECT_PLAN.md first (design), then adjust IMPLEMENTATION_PLAN.md if needed
3. **Code Review**: Check against IMPLEMENTATION_PLAN.md for consistency
4. **Design Decisions**: Always documented in PROJECT_PLAN.md with dates and reasoning
